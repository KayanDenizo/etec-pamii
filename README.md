# 📱 PAM II: ETEC Uirapuru

Atividades e projetos da disciplina **Programação de Aplicativos Mobile II** (2026), do curso técnico em Desenvolvimento de Sistemas da ETEC Uirapuru.

| Atividade | Descrição | Tecnologias | Data |
|---|---|---|---|
| [`01-interfaces-crud`](01-interfaces-crud/) | Interfaces em Java aplicadas a um CRUD de clientes, fornecedores e produtos | Java, Android | 03/2026 |
| [`02-cadastro-clientes-sqlite`](02-cadastro-clientes-sqlite/) | Cadastro de clientes e usuários com login e banco local SQLite | Java, Android, SQLite | 06/2026 |
| [`03-consumindo-api-cep`](03-consumindo-api-cep/) | Consulta de endereço por CEP consumindo uma API REST | Java, Android, Retrofit | 08/2026 |
| [`04-player-de-videos`](04-player-de-videos/) | Lista e reprodução de vídeos no app | Java, Android | 09/2026 |

## Como rodar

Cada pasta é um projeto Android completo: abra a pasta da atividade no **Android Studio**, aguarde a sincronização do Gradle e rode em um emulador ou celular.
